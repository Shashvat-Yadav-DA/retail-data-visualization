# Retail Sales Data Visualization

This project focuses on creating visual insights from a cleaned Retail Sales dataset using **Python** and **Matplotlib**.

## Overview

I transformed raw retail data into visual charts to identify key trends in sales performance and profitability.

## What I Did

* **Loaded cleaned data:** Imported the processed dataset into Python for analysis.
* **Created Visualizations:** Generated Bar charts, Line graphs, Histograms, and Scatter plots.
* **Analyzed Trends:** Examined the relationship between sales volume and profit margins over time.

## Files in this Project

* **Task6_Visualization.ipynb**: The main Jupyter Notebook containing all the Python code.
* **charts_output.pdf**: A PDF export of all generated charts for quick viewing.
* **Cleaned_Retail_Sales_Dataset.xlsx**: The source dataset used for the visualizations.
